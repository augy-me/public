# Rules

This repository is public, including its history and Actions logs.

- Write everything in English.
- Never commit personal data, secrets, deployment URLs or data files. Use Actions secrets or variables.
- Logs print counts and status only.
- Example values must be obviously fake (`example.com`).
- Check the diff before every commit.
- Push directly to `main`. Do not open pull requests.
- After finishing a task, always ask whether to wipe the git history.
